# Security policy

FitWitness is a research portfolio project. Its public demo runs on synthetic documents and synthetic money; it holds no real
personal data.

If you find a vulnerability, please report it privately with GitHub's **Report a vulnerability** (Security advisories) on this
repository instead of opening a public issue. Include what you did, what you saw, and the request that shows it.

What has been checked, what was fixed, and what is knowingly left open is in [docs/SECURITY.md](docs/SECURITY.md).
