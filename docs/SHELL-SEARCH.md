# 터미널 명령으로 하는 검색

채용 공고는 에이전트가 터미널 명령어 등을 써서 검색하는 능력을 말합니다. 반면 이 프로젝트의 원래 설계는 "어떤 도구도 셸 코드를 받지 않는다"였고(`docs/superpowers/plans`), 에이전트가 읽는 도면 텍스트는 신뢰할 수 없는 입력입니다. 그래서 `search_shell` 도구는 **셸이 아닙니다.** 명령어를 타이핑해서 검색하되, 허용된 범위 밖은 실행되지 않습니다.

## 무엇을 허용하는가

- 셸 프로세스가 없습니다. 명령줄을 직접 파싱해 최대 3단계로 나누고(`|`만 허용), 각 단계는 `grep`, `find`, `ls`, `head`, `tail`, `wc`, `sort`, `uniq`, `cut`, `cat` 열 가지 중 하나여야 합니다.
- 프로그램마다 허용하는 플래그 표가 따로 있습니다. `find`는 `-name -iname -type -maxdepth -mindepth`만, `grep`은 `-f`(패턴 파일)·`-P`(PCRE) 없이 일부 플래그와 `--include`·`--exclude`만 받습니다. 표에 없는 것은 거부합니다(`-exec`, `-delete`, `-fprint`, `sort -o` 등).
- 경로 인자는 이번 호출을 위해 만든 디렉터리 안에 머물러야 합니다. 절대 경로, `~`, `..`는 거부합니다.
- `;`, `&&`, `||`, `&`, `>`, `<`, 괄호는 거부합니다. 따옴표 안의 `$(...)`나 백틱은 셸이 없으므로 그냥 글자이며, 패턴으로 검색될 뿐 실행되지 않습니다.
- 프로그램은 CPU 4초, 메모리 768MB, 파일 쓰기 금지, 열 수 있는 파일 64개, 벽시계 5초 제한으로 실행하고 출력은 256KB에서 자릅니다.
- 검색 대상은 스냅샷의 활성 도면마다 만든 읽기 전용 텍스트 파일(도번, 개정, 제목, 종류, 패밀리, 추출된 사실 `fact material = SUS304`)입니다. 스냅샷 단위로 만들어 두고, 호출마다 스냅샷이 바뀌지 않았는지 확인합니다.

## 결과는 후보일 뿐입니다

출력은 파일 이름을 찾는 데만 읽습니다. 파일 하나가 도면 개정 하나이므로 결과는 다른 검색 도구와 같은 후보 목록이고(`scores: {shell: 출력 줄 수}`), 텍스트 자체는 에이전트에게 돌아가지 않습니다. 사실은 이전처럼 `query_dimensions`로 출처와 함께 읽어야 판정에 쓰입니다.

## 켜는 방법

기본은 꺼져 있습니다. 운영자가 `FITWITNESS_SHELL_SEARCH=on`을 켜야 하고, 열 가지 프로그램이 서버에 있어야 합니다. 공개 데모에서는 꺼져 있습니다.

## 확인한 것

- 단위 테스트 55개: 명령이 이름만 뽑아 후보로 돌려주는지(부정 검색 `grep -rL 'fact material' .` 포함), 거부해야 하는 45개 명령줄(셸 연산자, `find -exec`, `cat /etc/passwd`, `..`, 허용표 밖 프로그램과 플래그 등), 셸이 없다는 것(`$(touch 파일)`을 패턴으로 넣어도 파일이 생기지 않음), 시간 초과, 파일명 정리와 디렉터리 삭제. 셸이 있어야 되는 명령(경로의 `*.txt`, `-r` 없이 디렉터리를 grep)은 실행 전에 거부하고 바르게 치는 법을 메시지에 담는다는 것도 있습니다(아래 실측에서 모델이 친 명령 셋).
- 통합 테스트 4개: 실제 PostgreSQL 코퍼스에서 후보가 스냅샷의 개정과 일치하는지, 검색이 보는 텍스트가 저장된 사실과 같은지, 거부된 명령은 작업 디렉터리를 만들기 전에 거부되는지, 코퍼스가 바뀌면 stale로 거부하는지.
- 경로 게이트의 대본 에이전트 한 건: planner가 명령으로 검색하고(`tool:search_shell`), challenger가 아직 보지 않은 후보를 `query_dimensions`로 읽은 뒤 판정에 이르는 경로가 기준 경로로 커밋되어 있습니다.

## 한계

- 실제 모델 측정은 합성 도면 30장, 질의 8개(dev는 7개), 질의마다 한 번입니다. 반복이 없어 변동을 보지 못했고, 셸이 유리한 질의(열거, 부정)를 일부러 골랐습니다. 셸을 켜도 모델이 명령을 고르는 일은 드물었습니다(23번 중 5번).
- 검색 대상은 도번·제목·추출된 사실입니다. PDF 본문 주석이나 이미지 속 글자는 들어 있지 않습니다.
- 격리는 프로세스 수준의 제한입니다. 컨테이너나 seccomp 수준의 격리가 아니며, GNU 도구가 있는 리눅스를 가정합니다.
- 정규식이 폭주하면 시간 제한으로 끊깁니다. 도면 수만 개 규모에서의 비용은 재지 않았습니다.
