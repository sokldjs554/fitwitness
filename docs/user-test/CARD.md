# 과제 카드

주소: https://fitwitness.onrender.com/ (첫 화면이 30초쯤 걸릴 수 있습니다)

화면은 혼자 눌러 보시고, 생각나는 대로 소리 내어 말해 주세요. 잘하고 못하고를 보는 것이 아니라 이 도구가 어디서 헷갈리게 하는지 찾는 것입니다. 데이터는 전부 가짜입니다.

1. **도면 찾기.** 검토대에서 "장비에 고정할 브래킷을 찾아줘"처럼 원하는 부품을 자기 말로 적고, 구멍 간격 40, 재질 SUS304를 넣어 실행해 주세요. 결과 가운데 조건에 맞지 않는 도면을 하나 골라 왜 안 맞는지 말해 주세요.
2. **도번이 헷갈릴 때.** 도번 FW-002-4인 도면을 찾아야 하는데 "fw 002 4"라고만 기억납니다. 그렇게 넣어서 찾아 주세요.
3. **빠진 도면.** 결과 아래에 있는 "검색 제외"를 열어, 거기 있는 도면이 왜 빠졌는지 말해 주세요.
4. **보험금 청구.** 왼쪽 메뉴의 청구 심사로 가서 청구 한 건을 실행해 주세요. 결과가 지급인지 아닌지, 금액이 서류의 어디에서 나왔는지 찾아 주세요.
5. **중간에 멈췄을 때.** 청구 심사에서 "지급 기록 직후 중단 체험"을 켜고 청구 한 건을 실행한 뒤, 멈췄다는 안내가 나오면 다시 실행해 주세요. 보험금이 두 번 나갔는지 확인해 주세요.

다 끝나면 두 가지만 여쭙겠습니다. 어디서 제일 헷갈리셨나요? 이 화면이 뭘 하는 건지 한 문장으로 말하면요?
